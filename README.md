# sql-data-warehouse-project

Welcome to the **Data Warehouse and Analytics Project** repository! Yey !!

This project showcases an end-to-end data warehousing and analytics solution, covering the entire process from building a data warehouse to generating actionable business insights. Designed as a portfolio project, it demonstrates industry best practices in data engineering, data modeling, and analytics.

### Objective

Develop a modern data warehouse using Microsoft SQL Server to consolidate sales data from ERP and CRM source systems, enabling reliable analytical reporting and data-driven decision-making.

### Project Specifications

-**Data Sources** :

Import sales data from ERP and CRM systems using CSV files.

Review source structures, schemas, and data formats.

-**Data Quality and Cleansing** :

Identify and resolve data quality issues, including missing values, duplicates, inconsistent formats, and invalid records.

Standardise data to ensure consistency and accuracy before analysis.

-**Data Integration and Modelling**- :

Integrate data from both source systems into a centralised SQL Server data warehouse.

Design a user-friendly data model optimised for analytical queries and reporting.

Establish appropriate relationships between relevant entities and tables.

-**Data Scope**

Use only the latest available dataset.

Historical data tracking and historisation are outside the project scope.

-**Documentation**

Document the data warehouse architecture, table structures, relationships, and key business rules.

Provide clear documentation for business stakeholders, data analysts, and reporting teams.

---

### Expected Outcome

A consolidated, cleansed, and well-documented SQL Server data warehouse that provides a reliable foundation for sales analytics, business intelligence, and informed decision-making.
